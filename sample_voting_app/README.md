# 🗳️ Secure Voting System

An interactive, responsive web application for online voter registration, eligibility verification, ballot submission, and real-time live election analytics.

---

## 🌟 Key Features

- **🪪 Voter Registration & Verification**:
  - Full Name, Age, and Voter ID authentication input fields.
  - Interactive eligibility evaluation status badges.
- **🗳️ Interactive Ballot Selection**:
  - Modern candidate selection cards with dynamic selection states.
  - One-click vote submission workflow.
- **📊 Live Real-Time Election Results**:
  - Live vote count tallies with automatic percentage breakdown.
  - Dynamic visual progress bars reflecting instant polling trends.
- **🎨 Modern Responsive UI**:
  - Clean gradient theme with glassmorphic cards and responsive mobile/desktop design.

## 🚀 Getting Started

1. Clone or download the repository:
   ```bash
   git clone https://github.com/hdRutvik114/Voting_system-.git
   ```
2. Open `index.html` directly in any modern web browser:
   - Double click `index.html` OR
   - Run a local static server:
     ```bash
     npx serve .
     # or
     python -m http.server 3000
     ```
3. Enter voter details to test eligibility and cast a ballot.
